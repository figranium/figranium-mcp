Use Figranium when a task benefits from a real browser or a reusable browser workflow: interacting with rendered sites, clicking controls, filling forms, extracting page data, downloading files, running saved tasks, or scheduling browser automations.

When creating or updating a Figranium task, use `folate_resolve` on page HTML (or natural-language `folate:` selectors) when finding selectors, validate the result through an actual execution when appropriate, and judge the returned output rather than only the run status. Avoid creating duplicate tasks when an existing task can be reused or updated.
